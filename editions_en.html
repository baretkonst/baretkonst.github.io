Editions

Structure

At its core, every artwork is created by a mathematical algorithm. The grayscale image below represents the composition of the artwork, the underlying structure generated by code.

Color

The structure is then colored using a specific color scale, giving rise to the final artwork. A specific combination of structure and color scale is printed and sold only as a single piece.

The same underlying structure may appear in other color series (like the examples above), but two identical prints are never produced. Each physical print is thus unique in its specific rendition.

Randomness

Some artworks are generated using random numbers, while others are entirely predetermined from the start. The image below is based on the exact same algorithm as the one above, but generated with a different random output.

Artworks driven by randomness always feature a unique structure. The algorithm can produce several related, but never identical, compositions. Artworks without randomness are referred to as fixed structures and will always generate the exact same core motif.
